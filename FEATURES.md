# 🚀 Gelecek Özellik Fikirleri

Bu dosya, portföy sitesine eklenebilecek potansiyel özelliklerin listesini içerir.

---

## 🎨 Tasarım & UI

- [ ] **Özel Tema Renk Seçici** — Accent rengi admin panelinden değiştirme (mor, mavi, yeşil, turuncu vb.)
- [ ] **Animasyonlu Sayfa Geçişleri** — Bölümler arası smooth scroll + section giriş animasyonları
- [ ] **Responsive İyileştirmeler** — Tablet ve mobilde daha iyi UX

## 📊 İçerik & Veri

- [ ] **Blog Bölümü** — Markdown tabanlı blog yazıları ekleme, admin panelden yönetim
- [ ] **Proje Detay Sayfaları** — Her proje için modal veya ayrı sayfa ile detaylı bilgi (ekran görüntüleri, demo linki, README)
- [ ] **Testimonials / Referanslar** — Müşteri/iş arkadaşı yorumları bölümü
- [ ] **İstatistik Dashboard** — Ziyaretçi sayıları, en çok görüntülenen projeler (analytics entegrasyonu)
- [ ] **Eğitim Geçmişi (Timeline)** — Üniversite, kurslar, bootcamp'ler için ayrı timeline
- [ ] **Rozet Sistemi** — GitHub achievements benzeri başarı rozetleri

## 🔧 Teknik & Altyapı

- [ ] **PWA Desteği** — Service Worker + manifest.json ile offline çalışma ve ana ekrana ekleme
- [ ] **SEO Meta Etiketleri** — Open Graph, Twitter Card meta bilgileri
- [ ] **Lazy Loading** — Görüntüler ve bölümlerin tembel yüklenmesi
- [ ] **Performans Optimizasyonu** — CSS/JS minifikasyonu, critical CSS inline
- [ ] **Sitemap.xml & robots.txt** — Arama motoru optimizasyonu
- [ ] **RSS Feed** — Blog eklenirse RSS desteği
- [ ] **CI/CD Pipeline** — GitHub Actions ile otomatik deploy (Vercel/Netlify/GitHub Pages)

## 🌐 Sosyal & İletişim

- [ ] **Canlı Chat Widget** — Ziyaretçilerle anlık iletişim (Crisp, Tawk.to vb.)
- [ ] **Newsletter Aboneliği** — E-posta listesi toplama
- [ ] **Sosyal Medya Feed** — Twitter/X son tweetler veya LinkedIn paylaşımları
- [ ] **QR Kod Kartvizit** — Portfolyo linkini içeren QR kod oluşturma

## 🎮 İnteraktif Özellikler

- [ ] **Terminal/Konsol Modu** — Komutsatırı arayüzü ile portfolyoda gezinme (Easter Egg)
- [ ] **3D Proje Kartları** — Three.js veya CSS 3D transform ile kutu proje kartları
- [ ] **Müzik Çalar** — Arka plan lo-fi müzik seçeneği (mute/unmute)
- [ ] **Oyunlaştırma** — Portfolyoda gizli Easter Egg'ler, up-up-down-down kod vb.
- [x] **Scroll İlerleme Göstergesi** — Sayfanın neresinde olduğunu gösteren progress bar ✅

## 📱 Mobil & Erişilebilirlik

- [ ] **Gesture Desteği** — Mobilde swipe ile bölümler arası geçiş
- [ ] **Erişilebilirlik (a11y)** — ARIA etiketleri, klavye navigasyonu, ekran okuyucu desteği
- [x] ~~**Koyu/Açık Tema Sistem Tercihi**~~ — Kaldırıldı, sadece koyu tema kullanılıyor
- [ ] **Font Boyutu Ayarı** — Kullanıcının font boyutunu büyütüp küçültmesi

## 🔒 Güvenlik & Admin

- [ ] **İki Faktörlü Doğrulama** — Admin girişi için TOTP desteği
- [ ] **Yedekleme/Geri Yükleme** — Otomatik veri yedekleme programı
- [ ] **Admin Aktivite Logu** — Kimin ne zaman ne yaptığını takip
